# deepai-code-ru — русский интерфейс для DeepAI Code
## Установка

1. Скачайте репозиторий (**Code → Download ZIP**) и распакуйте.
2. Установите и запустите DeepAI Code.
3. Откройте настройки и отключите пункт **Automatically downloads stable DeepAI Code updates**.
4. Полностью закройте DeepAI Code, включая значок в трее.
5. В PowerShell из папки репозитория:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\rebuild-ru.ps1

Неофициальный русификатор окна **DeepAI Code** (десктопное приложение для Windows). Проект не связан с разработчиками DeepAI Code, это личная доработка «как есть». Файлы самой программы здесь не распространяются: в репозитории только словарь перевода и скрипты, которые накладывают его на **вашу** копию приложения.

> English version: [README.en.md](README.en.md)

## Что это даёт

В приложении нет встроенной смены языка: надписи зашиты в код интерфейса. Скрипт распаковывает серверную часть (`server.asar`), заменяет английские надписи по словарю (около 2500 строк) и собирает архив обратно. Оригинал сохраняется в резервную копию.

**Результат на практике:** переведена большая часть интерфейса — меню, названия пунктов настроек, кнопки, сообщения об ошибках, пустые состояния, многие пояснения. Часть надписей остаётся английской (например, левое меню настроек, некоторые заголовки разделов и пояснения под пунктами): они записаны в коде другим способом, и скрипт их пока не находит. Дополнения к словарю приветствуются (см. «Как помочь»).

## Требования

- Windows 10/11, PowerShell 5.1 (есть в системе).
- [Node.js](https://nodejs.org) (нужна команда `npx`, она скачает `@electron/asar`).
- DeepAI Code установлен для текущего пользователя (папка `%LOCALAPPDATA%\Programs\deepai-code-desktop`).

## Установка

1. Скачайте репозиторий (**Code → Download ZIP**) и распакуйте.
2. **Полностью закройте DeepAI Code** (в том числе значок в трее).
3. В PowerShell из папки репозитория:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\rebuild-ru.ps1
```

Скрипт идёт по шагам 1/6 … 6/6 и работает несколько минут. Он:
- распаковывает текущий `server.asar` в `%USERPROFILE%\deepai-work`;
- применяет словарь `dict\ru-dict.tsv`;
- собирает новый архив с теми же файлами «вне архива» (нативные модули) и проверяет, что список совпал;
- **только после успешной проверки** подменяет `server.asar`, предварительно сохранив копию в `%USERPROFILE%\deepai-work\server.asar.backup-<дата>`.

Если проверка не проходит, установленная программа не меняется.

4. Запустите DeepAI Code.

## Откат

Закройте приложение и верните резервную копию (команда с точным путём печатается в конце работы скрипта):

```powershell
Copy-Item "$HOME\deepai-work\server.asar.backup-ДАТА" "$env:LOCALAPPDATA\Programs\deepai-code-desktop\resources\server.asar" -Force
```

## Обновления приложения

Автообновление программы **заменяет `server.asar`, и русский пропадает**. Рекомендация:

- отключите автоскачивание обновлений в настройках (пункт «Automatically downloads stable DeepAI Code updates»);
- после каждого обновления просто запустите `rebuild-ru.ps1` заново: скрипт сам возьмёт новую версию и наложит перевод.

Если в новой версии структура файлов изменится, скрипт остановится с сообщением и ничего не сломает.

## Консольный pi (необязательно)

DeepAI Code работает на консольном агенте `pi`. Для самого `pi` в консоли можно подключить русский через пакет [`pi-di18n`](https://www.npmjs.com/package/pi-di18n):

```powershell
pi install npm:pi-di18n
powershell -ExecutionPolicy Bypass -File .\pi-console\install-pi-ru.ps1
```

Затем запустите `pi` и введите `/lang ru`. Статус: надпись в нижней строке меняется на русскую; перевод меню `/settings` и сообщений не проверен. На окно DeepAI Code этот пакет **не влияет**.

## Как это устроено (коротко)

Интерфейс окна — обычный веб-клиент внутри `server.asar` (`apps\server\dist\client\assets\*.js`). Скрипт заменяет только строки в определённых местах кода (после `children:`, `placeholder:`, `title:`, `label:`, `description:`, `text:`, `aria-label:`, `alt:`, `tooltip:`, `message:`, `header:`, `heading:`, `subtitle:`), поэтому логику программы не затрагивает. Названия продуктов (Claude, Codex, Cursor и др.) и технические описания для модели намеренно не переводятся.

## Как помочь

Словарь — обычный файл `dict/ru-dict.tsv`: на каждой строке английская фраза, табуляция, русский перевод (кодировка UTF-8). Присылайте pull request с новыми строками или правками. В переводе нельзя использовать обратную кавычку `` ` ``, `${`, обратную косую черту и прямые двойные кавычки (вместо них используйте «ёлочки»).

## Важно

- Вы изменяете файлы установленной программы **на свой риск**. Перед использованием убедитесь, что это не нарушает условия лицензии приложения.
- Репозиторий не содержит файлов приложения и не должен их содержать.
- Скрипты проверены вручную на одной конфигурации (Windows, DeepAI Code, ноябрь 2026).
